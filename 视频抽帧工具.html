视频抽帧工具

绿幕 / 黑底视频 → 像素风精灵表（Sprite Sheet）
  1. 准备视频：角色站在纯绿背景上原地做动作（跑步、待机、攻击…），镜头固定不动。一条视频里可以并排放 2～3 个角色，各占一块，互不接触。
  2. 载入：先选「一条视频几个角色」，再把视频拖进来。文件名带 正面 / 侧面 / 背面（或 front / side / back）会自动分到对应方向，带 跑 / 走 / 待机 / 攻击 会自动选输出规格。
  3. 选帧：拖到动作开始处，点「自动找循环」，跑步、走路选「两步」，其它选「一步」。工具会在首尾最接得上的位置均匀取帧。不满意的格子点一下，再用 ← → 换帧，按 Enter 放进去。
  4. 调整：看右边的预览。多个角色时用「同屏对比」和标尺把身高调一致（－ / ＋）。
  5. 导出：得到 PNG 精灵表，每行一个方向（正面 / 左侧 / 右侧 / 背面），每行从左到右是帧，另附几个放大尺寸和一份选帧记录（以后可以读回来接着改）。

全部在本机浏览器里处理，不上传任何文件。推荐用 Chrome 或 Edge。
