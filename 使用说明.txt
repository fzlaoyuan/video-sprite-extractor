视频抽帧工具 v2 · 使用说明
==========================

本包两个工具：
- 视频抽帧工具.html：角色动作（跑 / 走 / 待机 / 攻击）→ 精灵表，见第一至四节。
- 场景动画抽帧.py：场景物件（发光植物、地标、建筑的待机小动画）→ 精灵表，见第五节。

把绿幕（或黑底）动作视频变成像素风精灵表（Sprite Sheet）。
不用安装：双击「视频抽帧工具.html」，用 Chrome 或 Edge 打开就能用。
全部在本机浏览器里处理，不联网、不上传文件。

一、准备视频
- 角色站在纯绿背景上原地做动作（跑步、走路、待机、攻击……），镜头固定不动。
- 一条视频里可以并排放 2～3 个角色，各占画面的一半 / 三分之一，互不接触。
- 格式用 MP4（H.264）最稳；3～5 秒就够。
- 文件名带「正面 / 侧面 / 背面」（或 front / side / back）会自动分到对应方向；
  带「跑 / 走 / 待机 / 攻击」（或 run / walk / idle / attack）会自动选输出规格。

二、操作步骤
1. 载入视频：先选「视频里 1 / 2 / 3 个角色」，再把视频拖进页面。
   多个角色时，上面一排按钮切换角色，「名称」框里改名字（导出的文件名会用它）。
2. 选帧：拖到动作开始处，点「自动找循环」。
   跑步、走路选「两步：左右脚各一步」，其它动作选「一步」。
   工具会在首尾最接得上的位置均匀取帧。
   不满意的格子点一下，再用键盘 ← → 换帧，按 Enter 放进去。
3. 输出规格：选动作类型、帧数、格子大小（像素），另出尺寸用逗号分隔。
4. 预览：右边实时播放。多个角色时看「同屏对比」，用标尺把身高调一致。
5. 调整：「身高占格子」点 － / ＋ 改大小。
   抠图不干净就调「抠图强度」。颜色数、描边、亮度在折叠栏里。
   有现成的精灵表可以当「参考图」，自动校色、量身高。
6. 导出：「导出 PNG」导出当前角色，「导出全部角色」一次导出所有角色。
   文件在浏览器的下载文件夹里。

三、导出格式
- 每行一个方向：正面 / 左侧 / 右侧 / 背面（右侧默认由左侧镜像生成）。
- 每行从左到右是帧，格子是正方形。
- 主尺寸文件名不带后缀，另出的尺寸带 @尺寸，例如 小明_run@128.png。
- 「选帧记录.json」可以用「读取选帧记录」读回来接着改（视频要重新载入）。

四、常见问题
- 视频载入失败：浏览器不支持这个编码，用格式工厂之类转成 MP4（H.264）。
- 角色边缘有绿边：把「抠图强度」调小一点；有背景残留就调大一点。
- 跑起来一顿一顿：一般是选成了「一步」，跑步、走路要选「两步」。
- 电脑配置低：视频分辨率 1280×720 就够用，越短越快。

五、场景动画抽帧（植物 / 地标 / 建筑的循环小动画）
1. 首帧图：纯色背景（绿 / 品红 / 蓝，选和物件颜色差得远的），
   一张图放 1 个物件，或者 2×2 四个物件（每格中间放一个，互不接触）。
2. 用 AI 视频工具生成 3 秒视频，首帧和尾帧都放这张图（这样整段就是无缝循环）。
   提示词要点：固定机位不推拉；物件位置、大小、形状不变；只让发光、火焰、烟雾、
   叶片、水草等细节轻微动；最后回到和第一帧一样；背景始终同一种纯色；
   发光不要溢出物件轮廓。
3. 运行（需要先装 Python 3.9 以上，再执行 pip install opencv-python numpy pillow）：
   - 简单用法：把视频（可以多个，或整个文件夹）拖到「场景动画抽帧（拖视频到这里）.bat」上。
   - 命令行：python 场景动画抽帧.py 视频.mp4 --grid 2 --n 12 --size 128 --skip 1 3
     --grid 1 整个画面一个物件；2 = 2×2 四格（左上 1、右上 2、左下 3、右下 4）
     --n 帧数（12 帧 = 3 秒每秒 4 帧，比较顺）
     --size 每格输出边长；0 = 保持原大小
     --skip 哪几格没有动起来，就不出动画（只出静态图也行）
4. 结果在视频旁边的「抽帧结果」文件夹：
   - 视频名_格号.png：一行 n 帧的精灵表；_预览.gif：直接看效果
   - 动态太小的格子自动只出「_静态.png」，不浪费资源
   - 结果.txt：每格的动态幅度和输出
5. 工具已经处理的问题：自动识别背景色；发光和背景混出来的彩色光晕自动去掉
   （烟雾等灰色效果保留）；所有帧统一裁剪，烟雾飘出去也不会被裁掉。
6. 游戏里播放：按帧序号循环，3 秒一圈；同一种物件多个摆在一起时，各自错开起始帧，
   看起来就不会整片同步摇。
